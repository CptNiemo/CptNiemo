## Hi, I'm CptNiemo 👋

I run a homelab where AI, home automation, 3D printing and networking all meet. Mostly I build things so I can own my tools instead of renting them.

### What I'm about

A lot of great software is brilliant at one or two things, and then it comes with a subscription, another account, and your data on someone else's servers. I like to take the features I've found genuinely useful, rebuild them on open-source foundations, and combine them into an integrated, secure and modular one-stop shop that fits my own use cases and scales as they grow.

### What I'm working on

- 🤖 **AI**: local models and AI agents that help with everyday tasks, with guardrails and a human in the loop for anything that matters.
- 🏠 **Home automation**: Home Assistant at the center, tying devices, routines and dashboards together without depending on vendor clouds.
- 🖨️ **3D printing**: printer integrations and monitoring, plus functional prints for around the house and the lab.
- 🌐 **Homelab networking**: segmented networks, private remote access, single sign-on, and backups and monitoring I can trust.
- 🔓 **Open source**: swapping paid services for self-hosted alternatives, one niche at a time.

### How I like to build

- **Modular**: small pieces that can be swapped out without rebuilding everything.
- **Secure by default**: least privilege, isolated networks, and secrets kept out of code.
- **Personal, but scalable**: built for real everyday use first, structured so it can grow.
